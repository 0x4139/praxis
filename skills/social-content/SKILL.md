# Social Content

Write social content that reads native to each platform, not cross-posted slop.

## When to Activate

- Writing X posts, threads, or replies
- Drafting LinkedIn posts or launch announcements
- Scripting short-form video (TikTok, Reels, Shorts)
- Writing YouTube descriptions, intros, or chapter outlines
- Repurposing articles, demos, talks, or docs into social content
- Planning content around launches, milestones, or themes

## Core Rules

1. One idea per post. If you have three ideas, write three posts.
2. The hook carries the post. If the first line doesn't stop the scroll, nothing else matters.
3. Adapt for the platform. Never cross-post identical copy.
4. Use specifics over slogans. Numbers, names, outcomes — not adjectives.
5. Keep the ask small. One CTA, low friction.
6. Write like a person. No corporate voice, no AI filler.

## Platform Reference

### X (Twitter)

**Constraints:** 280 characters per post. Threads for longer content.

**Single posts:**
- Front-load the hook — first 50 characters decide engagement
- One claim, one proof point, one takeaway
- Skip hashtags in the body (use 1-2 only if they add reach)
- Links suppress reach — put them in replies when possible

**Threads:**
- Post 1 is the hook — must stand alone and create curiosity
- Each post advances the argument (not just continues the sentence)
- Number posts only if order matters for comprehension
- End with a summary post and CTA
- 5-12 posts is the sweet spot

**Hook patterns that work:**
```
[Surprising result] — here's how:
I [did X] and [unexpected outcome].
Most people think [common belief]. They're wrong.
[Specific number] lessons from [specific experience]:
Stop [common mistake]. Do this instead:
```

### LinkedIn

**Constraints:** 3,000 characters. First 2 lines visible before "see more."

**Structure:**
- Strong opening line — this IS the hook (appears before the fold)
- Short paragraphs (1-3 sentences max)
- White space between paragraphs
- Frame around lessons, results, or contrarian takes
- End with a question or soft CTA to drive comments

**What works:** personal experience + professional insight, launch announcements with context, contrarian takes on industry trends, lessons from failure.

**What doesn't:** motivational quotes, reshared articles without commentary, walls of text, excessive emoji.

### TikTok / Reels / Shorts

**Constraints:** 60-90 seconds optimal. Script to visuals.

**Structure:**
```
[0-3s]  Hook — interrupt attention, state the payoff
[3-15s] Setup — context, the problem, why this matters
[15-50s] Delivery — demo, walkthrough, proof
[50-60s] CTA — follow, try it, link in bio
```

**Rules:**
- Script around what's on screen, not abstract narration
- One demo or one claim per video
- Assume no sound for the first second (use text overlay)
- Captions are mandatory

### YouTube

**Constraints:** Long-form (8-20 min) or Shorts (< 60s).

**Long-form structure:**
- Show the result in the first 30 seconds
- Use chapters with clear labels
- Refresh visuals every 20-30 seconds
- End with a specific next video recommendation, not "like and subscribe"

**Description template:**
```
[1 sentence — what this video covers and who it's for]

Timestamps:
0:00 — [Chapter]
2:15 — [Chapter]

Links mentioned:
- [name]: [url]

[1 sentence CTA]
```

### Newsletter Promos

For promoting newsletter issues on social (the full issue is handled by `article-writing`):

- Pull the single most surprising insight from the issue
- Write it as a standalone post that delivers value even without clicking
- Link naturally — "I wrote about this in more detail" not "CHECK OUT MY NEWSLETTER"

## Repurposing Workflow

Turn one asset into platform-native content:

1. **Identify the anchor asset** — article, talk, demo, podcast, docs
2. **Extract 3-7 atomic ideas** — each must stand alone as a single post
3. **Write platform-native variants** — adapt format, length, and tone per platform
4. **Deduplicate** — if someone follows you everywhere, each platform should feel distinct
5. **Sequence** — stagger posts; don't flood all platforms the same day

### Repurposing Matrix

| Source | X | LinkedIn | Short Video | YouTube |
|--------|---|----------|-------------|---------|
| Blog post | Thread (key points) | Personal take + link | Demo the main insight | Expanded walkthrough |
| Product launch | Announcement + demo GIF | "Why we built this" story | 30s feature demo | Full demo + Q&A |
| Talk/podcast | Quote thread | Lessons post | Best 60s clip | Full recording + chapters |
| Customer win | Result tweet | Case study framing | Before/after | Interview format |

## Content Calendar

When planning content around a launch or milestone:

```
Day -7:  Teaser post (X, LinkedIn) — hint at what's coming
Day -3:  Behind-the-scenes (TikTok/Reels) — build anticipation
Day  0:  Announcement (all platforms, adapted per platform)
Day +1:  Thread with details (X) + "why we built this" (LinkedIn)
Day +3:  Demo video (YouTube/TikTok) + customer reaction if available
Day +7:  Lessons learned post (LinkedIn) + follow-up thread (X)
```

## Banned Patterns

Delete and rewrite any of these:
- "Excited to announce" (show, don't tell excitement)
- "Thrilled to share" (same)
- Hashtag spam (more than 3 hashtags on any platform)
- Empty engagement bait ("Agree?" "Thoughts?" with no substance)
- Cross-posted identical text across platforms
- Motivational fluff without concrete substance
- "Link in bio" as the only CTA without context

## Quality Gate

Before delivering:
- Hook would stop YOUR scroll — be honest
- Post reads native to its platform (length, tone, format)
- One clear idea per post, not three crammed together
- Specifics over adjectives (numbers, names, outcomes)
- CTA is low-friction and matches the platform
- No banned patterns
- If repurposed: each platform variant is distinct

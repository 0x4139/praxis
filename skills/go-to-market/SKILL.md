# Go-To-Market Strategy

Build a structured GTM strategy from problem statement to measurable launch plan.

## When to Activate

- Launching a new product or feature
- Entering a new market segment
- Repositioning an existing product
- Planning a pricing or distribution change
- Preparing for fundraising (investors expect a GTM story)

## The Process

Work through these steps in order. Each step produces a deliverable — don't skip ahead without completing the previous one.

### Step 1: Document the Core Problem

Everything starts here. If the problem isn't clear, nothing downstream will be either.

**Deliverable:** A problem statement in this format:

```
[Target customer] struggles with [specific problem] because [root cause].
This costs them [quantified impact: time, money, risk, opportunity].
Existing solutions fail because [gap].
```

**Quality check:**
- Is this a real problem you've validated (interviews, data, personal experience)?
- Can you quantify the pain? Vague problems produce vague strategies.
- Is the root cause something you can actually address?

### Step 2: Identify Your Target Market

Narrow down who you're building for. "Everyone" is not a market.

**Deliverable:** An Ideal Customer Profile (ICP):

| Field | Answer |
|-------|--------|
| Role / title | |
| Company size | |
| Industry | |
| Budget authority | |
| Current solution | |
| Trigger event | What makes them look for a solution *now*? |

**Segmentation tiers:**
- **Primary:** Highest pain, shortest sales cycle, best fit — launch here
- **Secondary:** Adjacent segment, expand after traction
- **Tertiary:** Aspirational, requires product maturity

**Quality check:**
- Can you name 10 real people or companies in your primary segment?
- Have you talked to at least 5 of them?

### Step 3: Research Demand and Competition

Understand the landscape before positioning yourself in it.

**Deliverable:** A competitive matrix:

| Competitor | Positioning | Strengths | Weaknesses | Pricing | Your advantage |
|-----------|-------------|-----------|------------|---------|----------------|
| | | | | | |

**Research checklist:**
- [ ] Market size (TAM/SAM/SOM) with sources
- [ ] Direct competitors (same problem, same approach)
- [ ] Indirect competitors (same problem, different approach)
- [ ] Substitutes (how customers solve this today without a product)
- [ ] Pricing benchmarks across the category
- [ ] Trends: is this market growing, shrinking, or shifting?

### Step 4: Find Your Positioning and Messaging

Position against the alternative, not the category.

**Positioning statement:**

```
For [target customer] who [situation/trigger],
[product] is a [category] that [key benefit].
Unlike [primary alternative], we [key differentiator].
```

**Messaging framework:**

| Audience | Pain point | Message | Proof point |
|----------|-----------|---------|-------------|
| Technical buyer | | | |
| Economic buyer | | | |
| End user | | | |

**Rules:**
- Lead with the outcome, not the feature
- One message per audience — don't try to say everything to everyone
- Every claim needs a proof point (data, case study, demo)
- Test messaging before committing — run it past real prospects

### Step 5: Create a Buyer's Journey Map

Map what happens between "never heard of you" and "paying customer."

```
AWARENESS → CONSIDERATION → DECISION → ONBOARDING → EXPANSION
```

For each stage, define:

| Stage | Buyer's question | Your answer | Content/action | Success metric |
|-------|-----------------|-------------|----------------|----------------|
| Awareness | "Do I have this problem?" | | | |
| Consideration | "What are my options?" | | | |
| Decision | "Why this one?" | | | |
| Onboarding | "How do I get value fast?" | | | |
| Expansion | "What else can this do?" | | | |

**Common mistake:** Over-investing in awareness (top of funnel) while the decision stage leaks. Fix the bottom first.

### Step 6: Pick Marketing Channels

Choose 2-3 channels max to start. Do them well before expanding.

**Channel evaluation:**

| Channel | Where your ICP is | Cost | Time to results | Measurable? |
|---------|-------------------|------|-----------------|-------------|
| Content/SEO | | | Slow (3-6 months) | Yes |
| Social (organic) | | | Medium | Partially |
| Paid ads | | | Fast | Yes |
| Community / events | | | Medium | Partially |
| Partnerships | | | Slow | Partially |
| Cold outreach | | | Fast | Yes |
| Product-led / viral | | | Varies | Yes |

**Selection criteria:**
- Where does your ICP already spend time?
- What's your budget? (No budget = content + community + outreach)
- What's your timeline? (Need results in 30 days = paid + outreach)
- What can you sustain? (A dead blog is worse than no blog)

### Step 7: Plan Sales

How does money change hands?

**Sales model options:**

| Model | Best for | Example |
|-------|----------|---------|
| Self-serve | Low ACV, high volume | Stripe, Notion |
| Sales-assisted | Mid ACV, some complexity | Linear, Vercel |
| Enterprise sales | High ACV, long cycles | Databricks, Snowflake |
| PLG + sales | Start self-serve, upsell | Slack, Figma |

**Define:**
- Pricing model (flat, usage-based, per-seat, freemium)
- Free tier or trial? What's the conversion trigger?
- Sales cycle length (days to close)
- Who signs the contract? (end user vs. manager vs. procurement)

### Step 8: Set Goals and Track Them

If you can't measure it, you can't iterate on it.

**Goal framework:**

| Metric | Baseline | 30-day target | 90-day target |
|--------|----------|---------------|---------------|
| Signups / leads | | | |
| Activation rate | | | |
| Conversion rate | | | |
| Revenue (MRR/ARR) | | | |
| CAC | | | |
| Time to value | | | |

**Rules:**
- Pick 3-5 metrics, not 15
- Set targets that are ambitious but not fantasy
- Track weekly, review monthly
- Every metric needs an owner

### Step 9: Refine and Iterate

A GTM strategy is a living document, not a PDF that sits in Google Drive.

**Monthly review:**
- What's working? Double down.
- What's not working? Diagnose before killing.
- What changed in the market? Adjust positioning if needed.
- What did you learn from customers? Update ICP and messaging.

**Pivot triggers:**
- Conversion rate below target for 2+ months
- Wrong buyer persona responding (enthusiastic users who don't pay)
- Competitors shipping your differentiator
- CAC exceeding LTV

## Deliverable Format

When the strategy is complete, produce a single document with:

1. **Problem statement** (Step 1)
2. **ICP and segments** (Step 2)
3. **Competitive landscape** (Step 3)
4. **Positioning and messaging** (Step 4)
5. **Buyer journey map** (Step 5)
6. **Channel plan** (Step 6)
7. **Sales model and pricing** (Step 7)
8. **Goals dashboard** (Step 8)
9. **Review cadence** (Step 9)

## Anti-Patterns

- **"Build it and they will come"** — no distribution plan, hoping for organic discovery
- **"Everyone is our customer"** — no ICP, messaging too generic to resonate with anyone
- **"We'll figure out pricing later"** — pricing shapes positioning; decide early even if you adjust
- **"Our product is our marketing"** — product quality is necessary but not sufficient
- **"We need to be on every channel"** — spreading thin across 8 channels, effective on none
- **"Let's just do what [big company] does"** — their GTM worked at their stage, not yours
